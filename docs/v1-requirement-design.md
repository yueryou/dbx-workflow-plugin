# DBX Workflow Plugin V1 需求设计方案

## 一、产品定位

> **"帮助开发人员定时/手动执行预定义的任务，将一种数据库的 SQL 转换成另一种或多种数据库的 SQL，减少重复操作和人为失误。用户可以定义任务步骤，配置任务通知等。"**

**核心关键词**：多库 SQL 方言转换 + 任务编排 + 通知

---

## 二、功能范围

### 2.1 核心能力矩阵

| 能力 | V1 支持 | V2 支持 | 说明 |
|------|---------|---------|------|
| **SQL 执行** | ✅ | - | 复用 DBX 已有连接 |
| **条件分支** | ✅ | - | 根据上一步结果决定后续流程 |
| **并行执行** | ✅ | - | 多个目标库同时执行 |
| **定时触发** | ✅ | - | Cron 表达式 |
| **手动触发** | ✅ | - | 点击按钮执行 |
| **文件操作** | ✅ | - | 读取本地 SQL 文件 |
| **企业微信通知** | ✅ | - | Webhook 通知执行结果 |
| **人工审批** | - | ✅ | 暂停等待确认 |
| **SQL 方言转换** | ✅ | - | MySQL ↔ PostgreSQL 等 |

### 2.2 SQL 方言转换（核心卖点）

**场景**：开发者写了一套 MySQL 的 SQL，需要转换成 PostgreSQL、Oracle、SQL Server 等版本执行。

**转换能力**：

| 转换类型 | 示例 |
|----------|------|
| 数据类型映射 | `DATETIME` → `TIMESTAMP` |
| 分页语法 | `LIMIT n` → `FETCH FIRST n ROWS ONLY` |
| 字符串函数 | `IFNULL()` → `COALESCE()` |
| 引号风格 | `` `name` `` → `"name"` |
| 自定义规则 | 用户配置正则替换 |

**用户自定义正则规则**：
- 支持配置正则表达式查找替换
- 可保存为规则模板供复用
- 支持导入/导出规则配置

### 3.2 数据流

```
用户定义工作流 → 保存到本地 JSON 文件
      ↓
触发执行（手动/定时）
      ↓
引擎解析 DAG → 按拓扑顺序执行
      ↓
每个节点：读取SQL → 方言转换 → 执行到目标库
      ↓
收集结果 → 更新图谱状态 → 发送通知
```

## 四、数据模型设计

### 4.1 工作流定义 (Workflow)

```json
{
  "id": "wf-001",
  "name": "MySQL 到 PostgreSQL 数据同步",
  "description": "将用户表从 MySQL 同步到 PostgreSQL",
  "version": 1,
  "tags": ["数据同步", "MySQL"],
  "trigger": {
    "type": "manual",
    "cron": "0 2 * * *"
  },
  "nodes": [
    {
      "id": "node-1",
      "type": "file_read",
      "label": "读取源 SQL",
      "config": {
        "path": "/scripts/user_query.sql"
      }
    },
    {
      "id": "node-2",
      "type": "sql_transform",
      "label": "MySQL → PostgreSQL 转换",
      "config": {
        "sourceDialect": "mysql",
        "targetDialect": "postgresql",
        "customRules": [
          {"pattern": "AUTO_INCREMENT", "replacement": "SERIAL"}
        ]
      }
    },
    {
      "id": "node-3",
      "type": "sql_execute",
      "label": "执行到 PostgreSQL",
      "config": {
        "connectionId": "pg-conn-001"
      }
    },
    {
      "id": "node-4",
      "type": "condition",
      "label": "检查行数",
      "config": {
        "expression": "node-3.affectedRows > 0"
      }
    },
    {
      "id": "node-5",
      "type": "notify",
      "label": "通知结果",
      "config": {
        "type": "wechat_webhook",
        "webhookUrl": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx"
      }
    }
  ],
  "edges": [
    { "from": "node-1", "to": "node-2" },
    { "from": "node-2", "to": "node-3" },
    { "from": "node-3", "to": "node-4" },
    { "from": "node-4", "to": "node-5", "condition": "true" }
  ],
  "created_at": "2026-09-22T10:00:00Z",
  "updated_at": "2026-09-22T10:00:00Z"
}
```

### 4.2 节点类型

| 节点类型 | 类型标识 | 功能 | 输入 | 输出 |
|----------|----------|------|------|------|
| 开始 | `start` | 工作流入口 | - | 流程开始 |
| 结束 | `end` | 工作流出口 | 流程结束 | - |
| 文件读取 | `file_read` | 读取本地 SQL 文件 | 文件路径 | SQL 内容 |
| SQL 转换 | `sql_transform` | 方言转换 + 自定义规则 | 源 SQL | 目标 SQL |
| SQL 执行 | `sql_execute` | 执行 SQL 到目标库 | SQL 语句 | 执行结果 |
| 条件判断 | `condition` | 根据条件选择分支 | 表达式 | true/false |
| 并行分支 | `parallel` | 并行执行多个子节点 | - | - |
| 等待 | `wait` | 延时等待 | 秒数 | - |
| 通知 | `notify` | 发送通知（预留扩展） | 消息内容 | 发送状态 |

## 五、API 设计（Host Bridge 方法路由）

### 5.1 工作流管理

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `workflow/list` | 列出所有工作流 | - | 工作流列表 |
| `workflow/get` | 获取工作流详情 | `{ id }` | 工作流定义 |
| `workflow/create` | 创建工作流 | `{ workflow }` | `{ id }` |
| `workflow/update` | 更新工作流 | `{ workflow }` | `{ success }` |
| `workflow/delete` | 删除工作流 | `{ id }` | `{ success }` |
| `workflow/validate` | 结构校验 | `{ workflow }` | `{ valid, errors, warnings }` |

### 5.2 执行控制

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `workflow/execute` | 触发执行 | `{ id, params? }` | `{ executionId }` |
| `workflow/stop` | 停止执行 | `{ executionId }` | `{ success }` |
| `workflow/pause` | 暂停执行 | `{ executionId }` | `{ success }` |
| `workflow/resume` | 恢复执行 | `{ executionId }` | `{ success }` |

### 5.3 执行记录

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `execution/list` | 执行历史列表 | `{ workflowId?, limit? }` | 执行记录列表 |
| `execution/get` | 执行详情 | `{ executionId }` | 执行详情+节点日志 |
| `execution/logs` | 节点日志 | `{ executionId, nodeId }` | 实时日志 |

### 5.4 SQL 转换

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `transform/sql` | SQL 方言转换 | `{ sql, sourceDialect, targetDialect, customRules? }` | `{ sql }` |
| `transform/dialects` | 支持的方言列表 | - | 方言列表 |
| `transform/rules` | 获取自定义规则 | - | 规则列表 |
| `transform/rules/save` | 保存自定义规则 | `{ rule }` | `{ id }` |

### 5.5 定时任务

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `schedule/list` | 定时任务列表 | - | 任务列表 |
| `schedule/create` | 创建定时任务 | `{ workflowId, cron }` | `{ id }` |
| `schedule/update` | 更新定时任务 | `{ id, cron }` | `{ success }` |
| `schedule/delete` | 删除定时任务 | `{ id }` | `{ success }` |

### 5.6 通知

| 方法 | 功能 | 请求参数 | 响应 |
|------|------|----------|------|
| `notify/test` | 测试通知配置 | `{ config }` | `{ success, message }` |
| `notify/send` | 发送通知 | `{ config, message }` | `{ success }` |
| `notify/types` | 支持的通知类型 | - | 类型列表 |
